# 实验日志

每次实验只测试一个 primary_variable。未写清变量、证据、阈值和停止线的活动不应叫实验。

## 实验卡

| 字段 | 内容 |
| --- | --- |
| experiment_id | EXP-YYYY-NN |
| 日期窗口 | 待填 |
| 当前阶段 | Day 0-30 / Day 31-60 / Day 61-90 |
| primary_variable | 例如：机构能否提供外籍客户书面价格 |
| HYPOTHESIS | 待填 |
| 反证条件 | 待填 |
| 最小动作 | 待填；不得包含未授权外发 |
| 允许/禁止范围 | 待填 |
| 观察指标 | 待填 |
| 数据来源与口径 | 待填 |
| 结果 | observed / contradicted / insufficient_sample |
| 失败层 | 目标 / 机制 / 设计 / 执行 / 证据 / 验收 |
| 后续决策 | continue / hold / stop / escalate |
| 复核人 | 待填 |

## 初始优先实验

| 优先级 | primary_variable | 成功证据 | 反证/停止 |
| --- | --- | --- | --- |
| 1 | 候选机构是否能提供书面外籍流程、价格、双语和异常/转诊 SLA | 至少一家完整、可复核的书面材料 | 无法取得，停止对外报价 |
| 2 | 三账报价是否可由责任主体解释并供专业方审核 | 范围、价格、退款、责任均可定位 | 任何账主体不清，Hold |
| 3 | 目标客户是否接受非疗效承诺的定位 | 匿名访谈重复出现明确价值/阻力 | 不将兴趣当订金 |
| 4 | 合格客户是否愿意支付可退款订金 | 实际到账、规则明确的订金 | 不支付则重判 Demand |
