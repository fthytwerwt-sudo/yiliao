# 供应商 / 机构核验记录

本表只记录机构能力与证据状态，不存储临床资料、私人联系方式或未授权谈判正文。公开网页是 FACT-B 线索，不等于通过 Gate。

## 通过条件

至少一家机构必须以可定位的书面材料证明：

1. 可以接待相应的外籍客户流程。
2. 相关服务范围和持证/机构主体明确。
3. 有真实书面价格、有效期、包含/不包含项。
4. 英文或双语交付的负责人、材料和范围明确。
5. 异常、紧急、转诊、取消与随访路径明确。
6. 项目方、机构和旅行伙伴的边界明确。
