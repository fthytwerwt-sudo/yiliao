# 漏斗指标

## 定义与口径

| 阶段 | 定义 | 不计入 |
| --- | --- | --- |
| Reach | 可归因地触达目标细分的人次/账户 | 无法判断是否属目标细分的泛曝光 |
| Lead | 主动留下合规联系意愿的线索 | 点赞、浏览、非授权名单 |
| Qualified Lead | 符合画像、预算、时间、边界且不在排除项 | 仅表达兴趣或需要临床判断者 |
| Evaluation | 完成非临床筛选和产品边界说明 | 医疗诊断或医院预审 |
| Formal Quote | 有供给依据、有效期和三账边界的书面报价 | 网页估算或口头报价 |
| Valid Deposit | 真实到账、可追踪、退款条件明确的订金 | 承诺付款、未到账或已冲回金额 |
| Arrival | 按约到达并进入服务路径 | 仅订票/口头计划 |
| Completed | 约定服务闭环完成 | 临床疗效或满意度保证 |

## 周期记录表

| --- | --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | --- | --- |
| YYYY-MM-DD 至 YYYY-MM-DD | 待填 |  |  |  |  |  |  |  |  |  | not_started | 待填 |

## 比率

- Lead rate = Lead / Reach。
- Qualification rate = Qualified Lead / Lead。
- Quote rate = Formal Quote / Evaluation。
- Deposit conversion = Valid Deposit / Formal Quote。
- Arrival conversion = Arrival / Valid Deposit。
- Completion conversion = Completed / Arrival。

只有同一窗口、同一渠道、相同定义的数据才能比较。小样本不出结论，零值需注明是零观测还是未收集。
