# 原始资料处理说明

## 原则

GitHub 存储的是当前结构化事实、版本裁决、证据规则、模板和匿名化复盘，不是原始市场报告、患者数据库或谈判资料仓库。

## 本轮原始资料

- 两份 DOCX 仅保留于本机路径，见 local_path_index.md。
- 原始 DOCX 默认不提交；.gitignore 已阻止常见文档和敏感路径进入仓库。
- 若未来某个资料需要进入版本库，先确认 GitHub 可见性、版权/授权、患者/隐私风险和用户的明确授权。

## 可以写入仓库

- 结构化结论、事实标签、来源索引和版本关系。
- 匿名化的实验、漏斗、单位经济、SLA 核验状态和异常统计。
- 不含秘密或个人/健康资料的执行模板。

## 不可以写入仓库

- 患者姓名、联系方式、健康/病历资料、证件、支付卡和可重识别记录。
- 密钥、Token、Cookie、私人授权、内部账号或未审查合同原件。
- 将公开机构资料加工成“已合作”或“已获许可”的虚假事实。

## 静态包边界

dist/gpt_project_sync_packages 下的包是可上传到 ChatGPT Project 的静态快照。生成包不等于用户已经上传，用户上传不等于 Project 指令或知识已生效，任何动态状态仍需回读 GitHub main。
