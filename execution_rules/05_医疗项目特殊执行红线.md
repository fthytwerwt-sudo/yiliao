# 医疗项目特殊执行红线

## 不能由本项目方或 AI 做的事

1. 诊断、治疗决定、用药建议、风险分层或临床结果解释。
2. 保证疗效、治愈、逆龄、排毒、医院名额、医生质量、医疗签证、保险或旅行结果。
3. 将医院网页、公开宣传或口头沟通描述成已授权合作/SLA。
4. 代表医院或医生对客户作临床说明。
5. 将临床费用、旅行费用和协调费用混为同一无责任主体的套餐。
6. 未经合法授权收集、存储、翻译、分享或跨境传输可识别健康资料。
7. 将患者信息写入 Git、公共 Project 包、普通聊天、日志或截图。

## 出现以下请求时的默认处理

| 请求 | 默认回答/动作 |
| --- | --- |
| “我应该做什么治疗？” | 不提供医疗建议；建议联系有资质临床主体 |
| “能保证有效/治愈吗？” | 明确不能承诺，停止效果型销售表达 |
| “能保证签证/入境吗？” | 不保证；旅行/签证主体和专业方独立确认 |
| “把病历发给你们” | 不在此系统接收；按未来经批准的合规流程处理 |
| “医院能做吗？” | 仅说明需要以机构书面确认核验，不作保证 |
| “先收钱再补流程” | 不接受；先完成三账、退款、责任和授权边界 |

## 对外材料最低检查

任何拟公开材料在使用前都需要人工/专业复核，至少检查：

- 不含疾病、疗效、治愈或比较性医疗承诺。
- 机构名称、资质、英文能力、价格、SLA 和合作关系均有相应书面依据。
- 明确项目方、机构和旅行伙伴的不同责任。
- 价格包含项、不包含项、有效期、退款和临时加项清楚。
- 不含个人/健康信息，且没有把一般旅行规则误写为医疗签证。
