# 商业模式与单位经济

## 商业模式

项目不是将医院临床服务打包成自身医疗收入的中介。项目方收入来自清晰、可解释、可退改审查的非临床协调服务，包括：

- 需求筛选与合格线索流程。
- 双语协调、材料流程、预约与日程组织。
- 时间管理、城市内衔接、旅行服务接口与跨境支持。
- 非临床随访协调和资料交接。

医疗/持证服务由机构向客户提供和收费；旅行服务由有资质旅行伙伴向客户提供和收费；项目方仅确认其自身协调服务账的收入和成本。

## 初始 P50 模型

以下均为 HYPOTHESIS，不是现有经营结果。

| 指标 | 初始候选 | 用途 | 真实验证来源 |
| --- | ---: | --- | --- |
| 客户总支付 | USD 4,800 | 客户体验的总口径 | 正式报价、订金、实际结算 |
| 项目协调确认收入 | USD 2,200 | 项目方可确认的收入 | 项目方合同/收款和退款数据 |
| 项目直接履约成本 | USD 850 | 直接协调、翻译、支持等成本 | 供应商票据、工时和履约记录 |
| 付费 CAC | USD 650 | 获得付费客户的成本 | 渠道归因和实际支出 |
| 单客贡献 | USD 700 | 初始商业假设 | 协调收入减直接履约成本与 CAC |

公式：

单客贡献 = 项目协调确认收入 - 项目直接履约成本 - 已归因付费 CAC。

贡献率 = 单客贡献 / 项目协调确认收入。

不要把医院临床费、旅行服务费、未到账订金、未收回退款或未归因获客支出混入项目协调收入。

## 当前扩张阈值

以下是 HYPOTHESIS / Gate，不是已达成 KPI：

- 付费 CAC P50 不高于 USD 900。
- 成行 CAC 不高于 USD 1,200。
- P50 单客贡献大于 USD 600。
- 贡献率原则上大于 25%。
- 至少 5 笔真实有效订金和 3 单实际成行。

若任一阈值没有足够样本，状态应为 UNKNOWN 或 INSUFFICIENT_SAMPLE，不得用少量正向个案宣布扩张。

## 90 天预算边界

HYPOTHESIS：预算上限约 USD 22,000。

优先用途：

- 中美法律、数据、合同与责任边界的专业复核。
- 供应商和全流程彩排。
- 双语产品材料、落地页草案及小规模渠道准备。
- 社区合作/高意图搜索的可归因测试。
- 履约和异常准备。

禁止把该预算默认用于开办公室、大规模品牌广告、复杂 CRM、大平台开发或提前扩充团队。

## 记录纪律

所有真实数据写入 review_loop/unit_economics.md，且每行必须有：

- 记录日期与数据窗口。
- 匿名 case_id 或聚合样本，不含患者身份/健康资料。
- 数据状态：observed、quoted、forecast、unknown。
- 证据定位：合同/账单/供应商报价/渠道账单的合规引用位置。
- 计算口径、退款/取消状态和复核人。
