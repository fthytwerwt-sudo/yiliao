# 事实状态与来源规则

项目事实状态：已确认、部分成立、待验证、推测、research_candidate、pending_decision、locked、superseded、blocked。

| 类型 | 应放位置 | 是否能定义项目战略 |
| --- | --- | --- |
| 当前已确认事实 | project_facts/01 | 只能描述已有证据 |
| 当前状态 | project_facts/02 | 只能描述当前锁定程度 |
| 未决策事项 | project_facts/03 | 不产生决策 |
| 正式决策 | project_facts/04 | 仅有 provenance 后可锁定 |
| 研究候选 | research_baselines/ | 否 |
| 候选执行模板 | candidate_playbooks/ | 否 |
| 协作机制 | collaboration_system/ | 否 |

完整的来源优先级和 No-Guess 规则以 collaboration_system/05 为 canonical。
