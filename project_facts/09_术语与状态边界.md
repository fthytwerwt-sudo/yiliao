# 术语与状态边界

## 证据标签

| 标签 | 定义 | 可以怎么用 | 不可以怎么用 |
| --- | --- | --- | --- |
| FACT-A | 政府、监管、医院官方原始资料 | 记录来源、日期、适用范围 | 外推为合作、成交或患者结果 |
| FACT-B | 企业/机构官网公开资料 | 作为供给或竞品线索 | 当作书面 SLA、可成交报价或授权 |
| FACT-C | 可靠二级资料 | 辅助背景判断 | 覆盖一手或真实交易证据 |
| INFERRED | 基于资料的合理推断 | 明示推理链和待验证动作 | 写成客观事实 |
| HYPOTHESIS | 需要测试的商业假设 | 建立实验、阈值和停止线 | 写成收入、成本或需求结果 |
| DECISION | 当前阶段选择 | 定义资源和任务优先级 | 冒充外部事实或永久真理 |
| UNKNOWN | 没有足够证据 | 阻断、列问题、设计核验 | 补数字、默认通过 |

## 完成态

| 状态 | 含义 |
| --- | --- |
| drafted | 已形成草案，未验证 |
| technically_checked | 格式/链接/YAML 等技术检查通过 |
| content_reviewed | 与当前事实和边界一致性已审 |
| human_review_required | 仍需用户或专业主体确认 |
| business_observed | 有真实交易/履约/外部书面证据 |
| formal_synced | 已进入 GitHub main 并远端回读 |
| blocked_need_alignment | 事实、权限或目标未对齐 |
| no_go | 已被反证或触发停止线 |

technically_checked、content_reviewed、formal_synced 都不等于 business_observed。

## 关键业务定义

- Qualified Lead：符合当前画像、预算和时间窗口；同意联系；不属于排除项；不代表会付款。
- Evaluation：已完成针对产品边界、时间、预算和需求的非临床资格评估；不代表医院预审。
- Formal Quote：基于书面供给、责任边界和有效期的正式报价；不是网页估算。
- Valid Deposit：真实到账、可追踪、退款条件明确、未被冲回的订金；候选金额不等于已验证规则。
- Arrival：客户按约到达并进入服务路径；不代表完成。
- Completed：约定的非临床协调和机构服务流程完成；不代表临床疗效。
- Contribution：项目协调确认收入减项目直接履约成本和已归因 CAC；不含医院/旅行收入。
- SLA：机构对流程、时效、责任、异常/转诊和语言支持的书面服务承诺；公开网页不等于 SLA。

## 唯一下一变量

每一轮实验只允许一个 primary_variable，例如“机构是否能给出外籍客户书面价格”或“合格客户是否愿意支付可退款订金”。不得一次改变客群、产品、价格、渠道和话术后仍宣称知道原因。
