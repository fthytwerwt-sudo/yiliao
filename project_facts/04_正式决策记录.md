# 正式决策记录

当前没有任何业务战略正式决策记录。

未来每个正式 DECISION 必须包含：

| 字段 | 要求 |
| --- | --- |
| decision_id | 唯一标识 |
| decision | 已锁定的明确选择 |
| decided_by | user / user_and_chatgpt / professional_authority |
| decision_date | 日期 |
| input_evidence | 已回读的事实、研究和专业输入 |
| alternatives_considered | 比较过的候选 |
| why_selected | 选择理由与限制 |
| scope | 适用范围和时间 |
| success_condition | 什么结果支持继续 |
| failure_condition | 什么结果反证 |
| revisit_trigger | 何时重新判断 |
| supersedes | 覆盖何种旧决定 |
| status | proposed / locked / superseded / retired |

不得使用 codex_decided。研究建议、Codex 候选和聊天推测不能跳过此记录。
