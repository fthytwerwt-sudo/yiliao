# 合规与责任边界

## 目的

本文件不是法律意见、医疗建议、机构授权证明或对外合同。它定义项目方必须保持的事实边界，并把必须由律师、医院/持证机构、旅行伙伴或支付专业方确认的问题提前暴露。

## 角色与责任分离

| 主体 | 可承担的责任 | 项目方不得替代 |
| --- | --- | --- |
| 医院/持证机构 | 临床判断、服务范围、资质、医疗价格、异常/转诊、临床记录和患者安全 | 诊断、治疗、疗效、医生资质和临床结果 |
| 旅行服务伙伴 | 合法旅行服务、酒店/车辆/行程责任、退改和旅行文件 | 旅行资质、签证/过境结果、保险承诺 |
| 项目方 | 非临床筛选、双语协调、预约、时间管理、资料流程、行程衔接、非临床随访协调 | 医疗服务主体、医疗收费主体、诊疗建议 |
| 律师/合规专业方 | 数据、广告、合同、跨境、支付、责任结构意见 | 由 AI 或项目方替代的法律结论 |

## 项目方禁止事项

- 不诊断，不改变治疗方案，不建议患者自行调整药物。
- 不承诺治愈、疗效、逆龄、排毒、临床结果、医生/名额、医疗签证或出入境结果。
- 不把医院公开信息包装为已授权合作。
- 不把旅游过境政策描述为医疗签证。
- 不在 Git、个人设备、普通聊天工具或未授权系统中储存/转发患者病历或健康资料。
- 不在没有明确授权和法律/机构边界前跨境传输健康数据。
- 不把尚未书面确认的英语服务、价格、异常处理、转诊或退款写成事实。

## 当前必须专业复核的清单

| 主题 | 需要回答的实际问题 | 当前状态 |
| --- | --- | --- |
| 医疗主体与广告 | 谁是服务主体，何种描述可能构成医疗广告或误导 | UNKNOWN，需律师/机构 |
| 跨境数据 | 联系、健康资料、翻译和随访各使用何种最小数据与授权 | UNKNOWN，需数据/律师 |
| 合同与退款 | 三方/多方合同、免责边界、取消、退款、异常与投诉路径 | UNKNOWN，需律师 |
| 支付 | 谁收取哪一账、订金属性、退款通道、税务和支付合规 | UNKNOWN，需支付/律师 |
| 旅行 | 旅行服务主体、资质、保险、车辆/酒店/签证陈述 | UNKNOWN，需伙伴/律师 |
| 临床异常 | 紧急、并发症、转诊、值班、语言支持和后续边界 | UNKNOWN，需机构书面 SLA |

## 最小数据原则

在当前仓库和 ChatGPT/Codex 工作流中只保留：

- 匿名 case_id、聚合漏斗数、状态、非敏感成本/收入口径。
- 证据类型、日期、责任方、是否有书面依据。
- 不含姓名、联系电话、证件号、诊断、检查结果、处方、病历、支付明细或可重识别组合。

若业务未来确需处理个人/健康信息，应先由专业方确定合法系统、访问控制、保留期限、跨境路径、授权记录和事故响应，再决定是否启动。
