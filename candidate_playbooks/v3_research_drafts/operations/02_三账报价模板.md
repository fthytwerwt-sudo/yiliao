# 三账报价模板

用途：将医疗/持证服务、旅行服务和项目协调服务的主体、价格与责任拆开。此文件是内部报价框架，不是对外合同、医疗价目表、收款授权或法律意见。

## 报价前置条件

- 每一项均有可定位的书面供给/主体/有效期依据。
- 临床服务主体、旅行主体和项目协调主体已分别确认。
- 不含任何患者身份或健康资料。
- 退款、取消、汇率、临时加项和异常责任经过相应专业方审核。

## 报价元数据

| 字段 | 填写内容 |
| --- | --- |
| quote_id | Q-YYYY-NN |
| 版本 / 日期 / 有效期 | 待填 |
| 适用 SKU | 成都东方健康管理 6 日体验或经批准的版本 |
| 客户匿名代号 | 可选；不得写姓名、证件或健康信息 |
| 汇率口径 / 税费说明 | 待填 |
| 供给证据定位 | 待填；不附未授权原件 |
| 审核状态 | draft / provider_review / legal_review / approved_for_authorized_use |

| 服务项 | 服务主体 | 服务范围 | 价格与币种 | 包含 / 不包含 | 有效期 | 临床责任 / 异常路径 | 书面依据 |
| --- | --- | --- | ---: | --- | --- | --- | --- |
| 待机构书面确认 | 待填 | 待填 |  |  |  | 由机构负责 | 待填 |

客户付款对象：医院或持证机构。项目方不得将此账描述为自身医疗收入或承诺临床结果。

## 第二账：旅行服务

| 服务项 | 旅行服务主体 | 服务范围 | 价格与币种 | 包含 / 不包含 | 有效期 | 取消/改期/保险/签证责任 | 书面依据 |
| --- | --- | --- | ---: | --- | --- | --- | --- |
| 待旅行伙伴书面确认 | 待填 | 待填 |  |  |  | 由伙伴负责 | 待填 |

客户付款对象：有资质旅行服务伙伴。国际机票默认不包含，除非有明确、可审查的主体和条款。

## 第三账：项目协调服务

| 服务项 | 项目方范围 | 价格与币种 | 包含 / 不包含 | 有效期 | 退款/取消 | 非临床责任边界 |
| --- | --- | ---: | --- | --- | --- | --- |
| 双语协调、预约、资料流程、时间管理、衔接与非临床交接 | 待最终范围确认 |  | 不含医疗/旅行主体责任 |  | 待专业审核 | 不诊断、不承诺效果 |

客户付款对象：项目方。项目协调服务候选 P50 为 USD 2,200，仅为 HYPOTHESIS；未有书面定价和授权前不得对外报价或收款。

## 总览与客户确认前检查

| 项目 | 金额 / 状态 | 说明 |
| --- | --- | --- |
| 客户总支付 | 待填 | 三账相加；不得让总价掩盖责任主体 |
| 医疗/持证服务账 | 待填 | 不计入项目协调收入 |
| 旅行账 | 待填 | 不计入项目协调收入 |
| 项目协调服务账 | 待填 | 仅此账进入项目单位经济 |
| 国际机票 | 默认不含 | 若包含必须单列主体和责任 |
| 临时加项 | 待填 | 必须先说明批准机制和付款主体 |

使用前确认：机构/旅行伙伴/项目方谁签、谁收、谁退、谁处理异常、谁提供客户支持，均不能空白。
