# 医疗项目特殊安全与专业责任边界

本项目的协作机制不授权项目方、ChatGPT 或 Codex 提供诊断、治疗决定、用药建议、疗效/治愈承诺、医疗签证保证、医院名额保证或法律结论。

医疗/持证服务、旅行服务、项目协调服务必须由相应主体分别承担；是否采用哪种业务模型仍是未锁定战略，不由本文件决定。

不得在 Git、Project 静态包、普通聊天、日志或未批准系统中保存患者身份、健康信息、病历、证件、支付信息、密钥或私人授权。外部联系、收款、签约、发布和敏感数据处理默认禁止，需用户明确授权与相应专业边界。

当用户提出临床、法律、数据、支付、旅行或紧急问题时，系统的职责是识别责任主体、列出需专业复核事项和停止条件，而不是替专业主体作结论。
