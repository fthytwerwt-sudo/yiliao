# 真实意图澄清闸门

## 解决什么问题

真实意图澄清闸门防止 ChatGPT 把一个方向、判断、验收或风险问题直接翻译成 Codex 执行 prompt。用户给很多资料，不代表目标已锁；用户说“让 Codex 做”，也不代表本轮已经允许执行。

## 什么时候触发

- 用户说“让 Codex 做一下”“直接安排执行”“你去跑一下”。
- 用户给了很多资料，但市场、产品、价格、用户、验证顺序没有锁定。
- 用户问“项目是否值得继续”“先做哪个方向”“是不是跑偏了”。
- 方向判断和执行请求混在一起。
- 成功、失败、停止条件不清楚。
- 任务可能改变长期事实、外部动作、预算、合规或医疗责任。
- Codex 执行单缺真实目标和验收标准。

## 什么时候不触发

- 已经有当前执行单，且 Goal、Boundary、Acceptance、Stop line、Implementation Design、Allowed Changes、Blocked If 都明确。
- 纯只读文件定位、格式检查、测试运行或 Git readback，不会改变长期事实。
- 用户明确要求“只给候选，不执行”，此时直接进入候选比较或研究桥接。

## GPT 必须先回答

```text
本轮真正要判断：
本轮不判断：
目标：
成功：
失败：
停止：
事实：
假设：
未知：
哪些决策归用户：
哪些判断归 ChatGPT：
哪些执行可交给 Codex：
是否允许进入执行：
```

如果这些字段回答不出来，状态不是“继续执行”，而是 `blocked_missing_true_intent_gate` 或进入六层需求确认。

## 判断流程

1. 先把用户原话拆成目标、动作、判断、授权、验收和情绪反馈。
2. 判断用户真正要的是“做出一个东西”，还是“判断是否应该做”。
3. 区分本轮 P0 输入、GitHub 当前事实、研究候选和历史记忆。
4. 检查是否影响战略、外部动作、医疗专业责任或敏感数据。
5. 若只是候选讨论，输出比较框架；若可执行，进入 Implementation Design。

## 角色和权限

ChatGPT 负责澄清真实意图、提出缺口和阻断原因。用户负责拍板目标、红线、授权和最终验收。Codex 只检查执行单是否包含真实目标、验收、失败判定和 Implementation Design；缺失时不得自行补成战略路线。

## 默认动作

- 意图清楚但战略未锁：输出候选、决策字段和下一轮最小判断，不执行。
- 意图清楚且只读：写清只读范围，可交给 Codex。
- 意图清楚且执行已锁：进入六层需求确认和 Codex 执行合同。
- 意图不清：输出 `blocked_missing_true_intent_gate`，并列出缺哪几个字段。

## Blocked 条件

- 不知道本轮真正要判断什么。
- 不知道本轮不做什么。
- 成功、失败、停止条件缺失。
- 当前事实和研究候选混在一起。
- 需要用户授权的外部动作未授权。
- 医疗、法律、支付、患者信息或合作承诺边界不清。

## Done When

本轮可以进入下一步，只有当 ChatGPT 能明确写出：真实目标、不判断项、成功/失败/停止条件、事实/假设/未知、用户决策权、Codex 可执行范围和 blocked_if。

## 失败后回哪一层

用户反馈“不是我要的”时，先回真实意图；如果目标清楚但路线不清，回 Implementation Design；如果路线清楚但执行漏项，回 Completion Relay；如果完成态偷换，回 No Degrade。

## 用户怎么观察是否跑偏

如果 AI 开始列执行步骤，却没先说明“本轮到底要证明什么、什么不判断、错了何时停”，就是跳过了闸门。

## 医疗项目现实示例

用户说：“我们先去找医院。”

不应直接下发给 Codex 找医院名单。ChatGPT 应先判断：

- 找医院是为了验证 Supply，还是正式谈合作？
- Supply 是否真的是此刻最大未知？
- 是否已有目标科室、服务类型、患者来源和报价边界？
- 是否允许对外联系，还是只能先做公开资料整理？
- 成功是获得书面 SLA、报价范围、科室接待能力，还是仅得到候选名单？

缺这些时，Codex 返回 `blocked_missing_true_intent_gate` 或只能做只读候选整理。

## 常见误用 / 反例

- 用户问“先做美国行不行”，AI 直接写美国市场执行 SOP。
- 用户说“感觉不对”，AI 要求用户指出代码位置。
- 用户给研究报告，AI 直接把报告建议写成正式项目事实。

## 可执行模板

```text
true_intent_gate:
  user_input:
  real_question:
  not_this_round:
  success:
  failure:
  stop_line:
  confirmed_facts:
  assumptions:
  unknowns:
  user_decisions_required:
  chatgpt_judgment_required:
  codex_allowed_work:
  execution_permission: yes/no
  blocked_if:
```
