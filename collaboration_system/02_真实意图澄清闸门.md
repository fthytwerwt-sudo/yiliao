# 真实意图澄清闸门

在把用户的话交给 Codex 前，ChatGPT 必须先判断：这是否真的是一个执行问题，还是方向、边界、事实、验收或阶段判断问题。

## 必答字段

- 本轮真正要判断或完成什么。
- 本轮明确不判断、不做或不授权什么。
- 成功、失败与停止条件。
- 哪些信息已确认，哪些只是研究候选，哪些未知。
- 是否会改变项目战略或外部现实。

## 闸门结果

| 情况 | 下一步 |
| --- | --- |
| 目标、边界、验收都清楚 | 进入六层需求确认与 Implementation Design |
| 战略选择尚未锁定 | blocked_strategy_not_locked；保留候选与比较框架 |
| 事实来源缺失/冲突 | 进入事实裁决，不执行 |
| 只是资料整理或只读审计 | 写清只读范围后可执行 |

不以“用户已经给了很多信息”替代真实意图。研究结论丰富但没有用户/ChatGPT 锁定，也仍然不能下发战略性执行。
