# 目标、边界、验收与停止线

每个任务在执行前都要有一个最小任务合同。

| 字段 | 问题 |
| --- | --- |
| Goal | 本轮真正要证明、改变或交付什么 |
| Context | 当前事实、研究输入和前序结果是什么 |
| Locked anchors | 哪些目标、范围、选项、标准已经锁定 |
| Constraints | 允许/禁止的文件、工具、外部动作、数据处理 |
| Acceptance | 技术、内容、人工、业务分别如何判断 |
| Stop line | 什么出现就停止、回退或请求用户决定 |
| Blocked if | 缺什么不能继续 |

目标未锁定时，Codex 只能整理候选、做影响检查或建立比较/验证设计，不能把候选当成计划。

医疗项目额外停止线：任何需要临床判断、法律结论、可识别健康信息、真实联系/收款或对外承诺的动作，均需相应责任主体与用户授权。
