# 外部调研、Perplexity 与 Reference 桥接

外部网页、Perplexity、行业报告、竞品、用户原话、原感稿和研究基线都先是输入，不是项目事实。

## 进入路径

1. 保存 source、date、scope、可访问性和原始主张。
2. 分开可观察事实、解释性推断、候选假设和不可迁移内容。
3. 写明对当前项目可能影响与仍缺的证据。
4. ChatGPT 判断是否需要进入正式决策讨论。
5. 若长期项目事实改变，按事实/决策记录回写 GitHub main。

Codex 可提取和结构化，不能从外部资料推导正式市场、产品、价格、合作、法规或业务状态。

对第三方资料不得复制品牌、界面、客户/个人信息或未授权内容。用户的原感/原话可保留为参考层，但不能替代 Implementation Design。
