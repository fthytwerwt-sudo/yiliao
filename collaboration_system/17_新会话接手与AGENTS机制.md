# 新会话接手与 AGENTS 机制

AGENTS.md 是新会话的最短入口，不是商业计划书。

新会话最低读取顺序：

1. AGENTS.md。
2. collaboration_system/00_总览_用户到现实反馈的完整闭环.md。
3. project_facts/00_项目身份.md、01_当前已确认事实.md、02_当前状态_project_state.yaml、03_当前未决策事项.md。
4. logs/latest.md 与 logs/current_target.md。
5. 当前任务对应的 collaboration_system、research_baselines 或 candidate_playbooks。

若发现战略未锁定、事实冲突、实施设计缺失、权限不足或来源无法回读，先输出明确 blocked 状态。不得因新会话缺上下文而把旧研究建议恢复为决定。
