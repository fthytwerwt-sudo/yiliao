# Data Goal Anchor 与单主变量

任何正式验证在战略锁定后才设置具体指标。当前策略未锁定时，本文件只定义方法，不产生市场、产品、价格、漏斗或门槛。

## 每轮锚点

- current_stage_goal：要减少哪一个关键未知。
- main_bottleneck：当前最重要的阻塞。
- primary_variable：本轮唯一主动改变的变量。
- supporting_variables：最多必要的协同调整。
- forbidden_variables：为保留归因而不动的变量。
- success_metric、failure_metric、observation_window。
- next_real_feedback 与 stop line。

若市场、产品、验证顺序未锁定，当前可记录的 primary_variable 是“选择哪条最小闭环进行比较”，而不是擅自开始某条路线的销售/供应链动作。
