# Project 静态协作包同步机制

## 允许内容

Project 静态包只包含用户 ↔ ChatGPT ↔ Codex 的长期协作机制：意图闸门、目标/边界、需求确认、事实裁决、路由、执行单、完成态、自修、单主变量、外部资料桥、四层分层、接手和医疗专业边界。

## 禁止内容

不得包含当前市场、客户、产品、价格、商业模式、Go Gate、90 天打法、供应商、渠道、latest、项目业务状态、研究报告摘要、真实指标或未授权资料。

## 三个独立状态

- package_generated：本地/仓库中已生成。
- user_uploaded_to_project_ui：用户已上传；只有用户或界面证据可确认。
- project_ui_verified：用户确认可用；不能由文件存在推断。

生成触发是协作机制变化，而不是项目业务方向变化。若市场从 A 改为 B、产品从 X 改为 Y，正确的 Package 不应需要修改。
