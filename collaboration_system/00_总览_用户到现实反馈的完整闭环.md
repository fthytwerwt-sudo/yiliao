# 协作操作系统总览

这是本仓库唯一的 canonical collaboration source。它只规定用户、ChatGPT、Codex、GitHub、Project、本地和 Obsidian 如何协作；不定义当前市场、产品、价格、验证顺序或商业结论。

## 完整闭环

用户提出目标或纠正 → ChatGPT 回读 GitHub main 的当前事实 → 识别真实意图、边界和未决策项 → 用户与 ChatGPT 锁定关键判断和 Implementation Design → Codex 在限定范围执行 → 技术/内容/人工/业务/同步分层验证 → GitHub main 回写动态事实 → 必要时复盘。

研究资料只能在“事实候选、推断或假设”位置进入这条链，不能绕过判断层变成项目战略。

## 关键边界

- Project 保存我们怎样协作；GitHub 保存项目现在真实是什么。
- 研究资料告诉我们可能怎么做，但不替我们做决定。
- Codex 执行已锁定决定，不替用户和 ChatGPT 决定项目战略。
- 未锁定战略时，默认状态是 blocked_strategy_not_locked，而不是让执行器选择一条看似合理的路。

## 阅读顺序

新会话先读 AGENTS.md，再读本文件、project_facts/00-03、logs/latest.md 和 logs/current_target.md；随后按任务类型读本目录对应章节。
