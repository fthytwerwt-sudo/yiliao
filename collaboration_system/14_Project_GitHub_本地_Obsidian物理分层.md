# Project、GitHub、本地与 Obsidian 的物理分层

| 层 | 保存什么 | 不保存什么 |
| --- | --- | --- |
| ChatGPT Project | 长期协作方法、项目指令、静态机制包 | 当前市场、价格、日志、业务状态 |
| GitHub main | 动态项目事实、正式决策、状态、研究索引、日志、代码 | 患者/个人资料、秘密、未授权原件 |
| 本地工作区 | 执行现场、临时文件、工具环境、未提交结果 | 自动等同于远端正式事实 |
| Obsidian | 可迁移机制、判断路径、案例、失败模式 | 医疗项目当前动态状态 |

信息从用户与研究进入 ChatGPT 判断，再由 Codex 写入 GitHub。Project 静态包和 Obsidian 都不得反向覆盖 GitHub main 的 current facts。
