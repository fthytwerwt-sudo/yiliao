# 退款、取消与异常处理模板

本模板用于设计可审查流程；不是最终对外条款或法律建议。任何真实收款、退款、医疗异常或数据事件均需由拥有相应责任和权限的主体处理。

## 事件分类

| 类型 | 示例 | 立即动作 | 责任主体 |
| --- | --- | --- | --- |
| 客户取消/改期 | 出发前时间变化 | 核验三账各自规则，冻结未确认承诺 | 相应收款主体 |
| 机构取消/改期 | 预约不可用、服务范围变化 | 通知客户、寻找合规替代或停止 | 机构负责服务说明 |
| 旅行异常 | 酒店、车辆、行程取消 | 按旅行伙伴条款升级 | 旅行伙伴 |
| 医疗/临床异常 | 不适、紧急、需要转诊 | 不作临床判断，立即按机构紧急/转诊路径升级 | 医疗/持证机构 |
| 数据/隐私异常 | 误收、误发、可识别资料泄露 | 停止传输、保全最小事实、专业升级 | 合规/法律/数据责任主体 |
| 边界/投诉 | 疗效承诺、责任不清、误导表达 | 暂停相应材料/服务，记录事件 | 项目负责人 + 专业方 |

## 事件记录卡

| 字段 | 内容 |
| --- | --- |
| incident_id | INC-YYYY-NN |
| 日期和匿名范围 | 待填 |
| 已确认事实 / UNKNOWN | 待填 |
| 涉及的账目和责任主体 | 医疗 / 旅行 / 协调，分别填 |
| 客户沟通由谁负责 | 待填 |
| 临时控制 | 待填 |
| 退款/费用依据 | 待填 |
| 是否需专业升级 | 待填 |
| 复盘与流程修复 | 待填 |

## 对外沟通底线

- 不猜测临床原因、疗效或法律责任。
- 不代表机构/旅行伙伴作承诺。
- 不在普通聊天中要求/接收病历或可识别健康信息。
- 不为了安抚客户而承诺超出书面条款的退款、名额、签证或结果。
