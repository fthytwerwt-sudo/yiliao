# 医院 / 机构 SLA 核验模板

用途：核验候选机构是否能支持第一款跨境 wellness SKU。此模板不是合作协议，不代表项目方已获得授权，也不替代机构、律师或医疗专业人员的书面意见。

## 核验元数据

| 字段 | 记录 |
| --- | --- |
| supplier_id | 待填 |
| 机构名称/主体 | 待填 |
| 核验日期 / 核验人 | 待填 |
| 证据状态 | public_claim / written_response / signed_sla / unknown |
| 证据定位 | 待填；Git 不存敏感原件 |
| 适用 SKU / 服务范围 | 待填 |
| 结论 | pass / hold / fail / insufficient_evidence |

## 必须核验项

| 类别 | 必问/必证项目 | 机构书面回答 | 状态 | 影响 |
| --- | --- | --- | --- | --- |
| 主体与资质 | 服务主体、科室、持证/资质与可提供范围 |  | UNKNOWN | 无法确认则不可销售 |
| 外籍流程 | 是否真实接待外籍客户、材料、预约提前期、负责人 |  | UNKNOWN | Gate 必填 |
| 语言 | 英文/双语联系人、现场支持、材料、报告语言 |  | UNKNOWN | 不可口头承诺 |
| 价格 | 项目明细、币种、税费、有效期、包含/不包含、临床新增费用 |  | UNKNOWN | Gate 必填 |
| 服务交付 | 预约、到院、评估、报告、交付时效 |  | UNKNOWN | 需写明时效 |
| 异常/紧急 | 紧急处理、值班、语言支持、转诊和升级联系人 |  | UNKNOWN | Gate 必填 |
| 退款/改期 | 谁决定、触发条件、时间、费用和证据 |  | UNKNOWN | 三账必须一致 |

## SLA 最低文本要素

书面 SLA 至少应能回答：

1. 谁负责什么，何时响应，如何升级。
2. 外籍客户进入流程所需材料、预约提前期和拒绝/变更机制。
3. 服务和报告的语言、时效、费用、有效期及临床新增费用规则。
4. 紧急、并发症、转诊、取消、退款、投诉和后续交接的责任主体。
5. 数据/资料的收集、传输、翻译、保留和授权边界。

## Gate 判定

- Pass：所有必填项有可定位书面证据，且专业复核路径明确。
- Hold：存在可修复缺口，未向客户或市场作正式承诺。
- Fail：机构不能/不愿提供核心书面流程、价格、语言或异常责任。
- Insufficient evidence：只有公开资料或口头说明。
